# Xpeed POS — offline–online sync

Public sample of the data-sync core behind **Xpeed POS**, a cross-platform point-of-sale system for restaurants and retailers — live table tracking with seamless offline–online synchronization, so sales keep flowing when the connection drops.

Built at XpeedLab (2023–2024); the full production system is private.

**Stack:** Electron.js · Next.js · Node.js · SQL

More at [smrifat1411.github.io](https://smrifat1411.github.io).
